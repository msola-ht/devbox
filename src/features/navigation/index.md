# 导航索引

组合侧栏、路由入口和用户展示，路由定义位于 [app-routes.ts](../../app-routes.ts)。

- [app-sidebar.tsx](app-sidebar.tsx)：侧栏整体组装。
- [data.ts](data.ts)：团队、用户和导航的静态展示数据。
- [model.ts](model.ts)：导航、团队、用户和侧栏的数据类型。
- [nav-main.tsx](nav-main.tsx)：主导航、当前页面状态和移动端导航收起。
- [nav-projects.tsx](nav-projects.tsx)：项目分组与“更多”展示入口。
- [nav-user.tsx](nav-user.tsx)：用户头像、名称和操作菜单展示。
- [team-header.tsx](team-header.tsx)：团队标识与名称展示。
- [page-breadcrumb.tsx](page-breadcrumb.tsx)：面包屑展示。
