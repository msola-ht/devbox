# Rust 后端架构约束

本文件适用于 `src-tauri/**`，补充根目录规则，仅定义结构、职责与依赖约束。

## 目录与职责

```text
src-tauri/src/
  main.rs                  # 平台入口
  lib.rs                   # 组装应用、注册 command、注入依赖
  state.rs                 # 应用服务与资源句柄
  ipc/
    mod.rs                 # IPC 模块出口
    error.rs               # 可序列化的边界错误
    <feature>.rs           # command 与该业务的 IPC DTO
  modules/
    mod.rs
    <feature>/
      mod.rs               # 受控公开接口
      model.rs             # 领域模型与不变量
      service.rs           # 用例编排和事务边界
      repository.rs        # 有必要时定义持久化接口
      error.rs             # 该业务的类型化错误
  infrastructure/
    mod.rs                 # 基础设施模块出口
    storage/               # 持久化实现，按实际介质建立
    filesystem/            # 文件系统适配，按实际需要建立
```

- 文件按实际职责创建，简单模块可合并文件；不预建空目录或无用途的抽象。
- `main.rs` 与 `lib.rs` 不承载业务流程，`state.rs` 不演变为统一业务服务。
- IPC 依赖应用服务；应用服务依赖领域模型，以及按下述条件选定的资源接口或具体适配。资源接口由业务模块定义，基础设施提供实现，`lib.rs` 负责依赖组装。领域模型始终不依赖 Tauri、IPC DTO、具体适配或存储框架。
- Rust 业务模块不调用其他模块的 command；协作通过模块公开服务或上层编排完成，不访问其他模块的存储内部实现。
- 默认私有，按需要使用 `pub(super)`、`pub(crate)` 或 `pub`；不为方便跨模块访问公开全部字段。实体不变量由构造与更新方法维护。
- 只有单一存储实现且用途限于本模块时，应用服务可以依赖该模块使用的具体适配；适配可以位于 `infrastructure/`，但不能将数据库行、连接、事务句柄或框架类型泄漏到业务模块公开接口。
- 存在多种适配实现、应用服务需要脱离当前适配独立复用，或资源能力需要跨业务模块使用时，通过资源接口隔离依赖；跨模块调用仍经过所属模块的公开服务，不直接访问其存储适配。是否抽象由依赖需求决定，不以模块大小决定。
- 跨业务模块的一致性操作归 Rust 应用服务或明确的上层编排服务；事务与补偿边界在该用例内定义，不依赖前端调用顺序。上层编排服务按需建立，参与模块不能反向依赖它。

## 数据与错误

- Rust 执行最终输入校验和业务授权，包括名称、路径、资源归属与状态转换；不能信任前端已禁用按钮或已校验输入。
- 数据库一致性由事务维护，跨文件或外部进程的操作定义失败恢复或补偿语义。返回成功意味着契约承诺的持久化或任务登记已完成。
- 业务失败使用类型化错误传播；边界统一映射稳定错误码。预期的无效输入、资源不存在、冲突和 I/O 失败不得使用 panic、unwrap 或 expect 处理。
- 运行时日志可记录内部诊断上下文，但不包含密钥或敏感载荷；IPC 仅返回安全信息。

## 状态、并发与任务

- 应用状态保存服务、连接池及受控任务注册表；按资源和业务拆分，不使用覆盖整个应用的单一可变状态锁。
- 共享所有权与同步按实际并发需求选择；不对所有值机械套用 `Arc<Mutex<_>>`。锁只保护短时一致性更新，不跨外部 I/O 或长任务持有，不持同步锁跨越 await。
- `async` 不代表阻塞工作自动离开执行器；阻塞文件操作、同步库调用和 CPU 密集计算使用适合的阻塞任务或工作线程，明确并发上限。
- 长任务有唯一 ID、所属资源、明确状态和结果查询入口；状态转换区分等待、运行、取消请求、取消完成、失败和完成。
- 任务取消采用协作机制并覆盖实际子操作；子进程、文件句柄、订阅及临时资源具有明确所有者和结束策略。前端窗口关闭是否终止任务由任务契约定义。
- channel 或 event 传输通知或流数据，Rust 注册表或持久化记录保存任务权威状态与结果；发送失败不能被误判为业务成功或自动重启任务。
- 任务队列、日志缓冲和消息积压有容量或保留上限；重试有次数与时间边界，写操作具有明确幂等语义。
- 持久业务数据包含格式版本与迁移语义；损坏数据不能被静默当作首次启动并覆盖。仅需进程内存活的状态不强制落盘。
